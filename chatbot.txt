RETRIEVAL PIPELINE

User Question
      |
      v
Normalize Text
(lowercase, strip punctuation)
      |
      v
Embed Question (bge / e5)
      |
      v
FAISS Search (Top-1 only)
      |
      v
If similarity < 0.75:
    -> "This question is not covered in SOP"
Else:
    -> Return stored answer (ground truth)


##################################################################	


HALLUCINATION PREVENTION RULES

[ RULE 1 ] LLM is NOT allowed to answer questions
[ RULE 2 ] LLM can only rewrite retrieved answer
[ RULE 3 ] Top-1 retrieval only
[ RULE 4 ] Hard similarity threshold
[ RULE 5 ] Reject unknown questions
[ RULE 6 ] Return verbatim SOP answer
